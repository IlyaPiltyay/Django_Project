# Django Project

## Описание
Это проект на Django, который представляет собой каталог товаров. Он включает в себя приложение `catalog` для управления продуктами и их отображения на веб-странице.

## Требования
- Python 3.12 или выше
- Django 4.x или выше
- Poetry (для управления зависимостями)
